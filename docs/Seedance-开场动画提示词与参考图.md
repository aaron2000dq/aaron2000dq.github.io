# Exploration Atlas · Seedance 开场动画方案

## 推荐成片

- 模型：Seedance 2.0
- 比例：16:9 横屏
- 时长：10 秒
- 分辨率：先生成 1080p
- 结构：单镜头、无人物、无对白
- 用途：在网页交互信封出现之前播放；视频最后一帧与网页信封界面交接

不建议让模型直接生成标题或中文。AI 视频里的文字很容易变形，正确做法是让
Seedance 生成“无文字信封终帧”，随后由网页淡入真实的
`EXPLORATION Atlas` 和中文故事文案。

## 全能参考模式：可直接复制的提示词

```text
生成一段 10 秒、16:9、24fps 的电影级奇幻探索开场，单一连续镜头，无剪切。

整体美术严格参考 @图片1：深色旧木桌、古老羊皮纸、黄铜航海仪器、烛火照明，
色彩控制在黑棕、旧金、暗红和暖象牙色之间。画面精致、真实、克制，具有古典
铜版探险图鉴与高端电影道具质感，不要做成卡通，不要出现任何现成影视 IP 标志。

0–1.5 秒：
镜头从接近全黑的木桌上方缓慢苏醒。烛火依次点亮，桌上的黄铜罗盘刻度出现极轻微
反光，空气中只有少量尘埃，摄影机以非常缓慢、稳定的俯拍推进开始运动。

1.5–3.8 秒：
一只外形严格参考 @图片2 的仓鸮从画面左上方掠过，只出现一只。翅膀遵循真实空气
动力学自然振动，羽毛层次清晰，带起两三片细小羽毛和柔和风压。猫头鹰脚下携带
一封信，动作快速但稳定，不遮住整个画面。

3.8–5.8 秒：
猫头鹰释放信封后飞出右上方。信封落到羊皮纸中央并轻轻滑行，纸张有真实重量和
摩擦，最终停住。信封造型、金属护角、红线结构严格参考 @图片3，不允许折断、
融化或变形。摄影机继续非常轻微地向信封推进。

5.8–7.5 秒：
暗红蜡封参考 @图片4，从温暗状态逐渐亮起一圈细微金光。桌边黄铜纹路被依次唤醒，
产生很克制的星屑和罗盘刻度光，不出现爆炸，不出现大面积烟雾。纸张边缘随风轻动，
烛光在金属护角上掠过。

7.5–10 秒：
信封在魔法力量下自然展开，中央信纸升起，摄影机平稳完成最后一次极小幅推进。
画面逐渐、精确地对齐 @图片5 的信封大小、中心位置、俯拍角度、焦距、背景结构和
明暗关系。信纸保持完全空白，不生成任何字符。最后 0.8 秒镜头完全稳定，所有物体
停止移动，只保留非常轻微的烛火呼吸，便于和网页无缝交接。

声音：
立体声、无对白、无配乐主旋律。包含远处夜风、一次自然的仓鸮振翅、信封落桌和
纸张摩擦、低沉克制的蜡封共鸣、很轻的黄铜机械咔哒声、烛芯燃烧声。第 9 秒出现
一颗极轻的钢琴单音，随后自然衰减。

严格限制：
无文字、无字母、无数字、无字幕、无水印、无标志；不出现人物、手、魔杖、城堡、
校徽或任何电影 IP 元素；只有一只猫头鹰；不切镜头、不快速摇镜、不鱼眼、不手持
抖动、不速度拉伸；信封不能弯曲融化，蜡封不能变形；粒子数量克制；最后一帧必须
干净、稳定并对齐 @图片5。
```

## 只有“首尾帧”模式时

- 首帧：使用 `@图片1`
- 尾帧：使用 `@图片5`
- 仍然使用上面的时间轴提示词
- 删除提示词中对 `@图片2–4` 的引用，改成文字描述
- 优先生成 8–10 秒，不要一次追求 15 秒

首尾帧模式更容易获得无缝衔接；全能参考模式更容易保住猫头鹰、信封和蜡封的
具体造型。建议先各生成两版，再用“最后一帧是否能和网页无感切换”作为唯一筛选
标准，而不是只看中间是否华丽。

## 建议再生成的两个备选版本

### 克制版

删掉猫头鹰，只让一枚黄铜罗盘在桌上自行转动，指针停止后信封从阴影中滑出。
优点是更稳定、质感更高级，缺点是故事性稍弱。

### 完整地图版

把最后 3 秒改成信封完全打开，信纸变成
`public/assets/maps/rehearsal/05-fuli-north-four-gates-v1.png` 的精细羊皮纸地图。
这个版本适合未来直接替代现有网页开信动画，但需要重新设计网页跳转点，不建议
作为第一版。

## 导出与交付

- 文件格式：MP4
- 视频编码：H.264
- 音频编码：AAC 立体声
- 建议码率：1080p 使用 5–8 Mbps
- 结尾保留至少 0.8 秒静止画面
- 不要在 Seedance 中添加字幕；所有标题由网页渲染

拿到成片后，先不要自行压缩。把原始文件放进项目，我会负责：

1. 检查首尾帧和网页的像素级衔接；
2. 生成适合 iPad Safari 的 MP4；
3. 增加静音策略、`playsinline`、跳过按钮和加载失败兜底；
4. 缓存到 PWA，保证当天弱网也能播放。
